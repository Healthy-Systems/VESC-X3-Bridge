VESC-X3-Bridge
Installable VESC package for integrating VESC controllers into the Ninebot Max G3. Compatibility with other Ninebot Max 3-series models is still under evaluation.

Features:
VCU / Dashboard communication
Star-Delta motor switching
TempGuard temperature monitoring and protection
Rearlight LED control
Configurable safety functions


Compatibility:
Ninebot Max G3: Main development and test platform
Other Ninebot Max 3-series models: Compatibility not yet confirmed
